# Portfólio estático

Versões em HTML do portfólio de Ezequiel Lobo Oliveira.

- [index.html](index.html) é a página inicial.
- [index1.html](index1.html), [index2.html](index2.html) e [index3.html](index3.html) registram outras versões do layout.
- [assets/](assets/) reúne os recursos do site.

Abra `index.html` no navegador para explorar a versão local. O código da versão mais recente do portfólio está no [repositório ezequiel-lobo-portfolio](https://github.com/EzekLobo/ezequiel-lobo-portfolio).
